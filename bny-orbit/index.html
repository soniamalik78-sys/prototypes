The customer moment

The assistant drafts “settled” from a stale record. A grounding check compares it with the custody ledger, finds the payment pending, blocks the reply and rewrites it as “pending, expected date shown”. Because it concerns client assets, a service specialist approves before it reaches the client. Sources, model version and approver are logged.

Architecture & developer experience

Experience: client-service assistant and service-specialist approval console.
Builder agents: requirements drafting, AI-assisted code, context-aware tests, release notes.
Judge agents: score each change against a custom rubric (accuracy, security, grounding); reviewers decide from that evidence.
Evaluation: golden datasets, negative DAST scenarios, regression suites run on every merge.
Governance: risk tiers, approved-tool inventory, named human approvers for regulated paths, evidence trail kept for audit.
Platform: BNY's Eliza enterprise AI platform (public), approved models, custody ledger as system of record.

Developer experience

  • Feedback on a change in minutes, not after a review queue.
  • Shared prompt templates and reusable test components, so the governed route is also the fastest.
  • Early AI/ML pioneer: applied machine learning to production defect and Sev2 incident management at Audible from 2022, before AI went mainstream.
  • Hands-on proof: testing at S&P Global caught AI-generated code exposing server directory structure in an error response, and negative DAST scenarios revealed log files exposing details to AI models.
