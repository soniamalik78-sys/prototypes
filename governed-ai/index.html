How controls catch problems ILLUSTRATIVE SCENARIOS

A. Sensitive data in a prompt illustrative

A shared template flags customer identifiers before submission; the developer sees a masked alternative.

B. Stale retrieval source illustrative

An evaluation gate detects an outdated reference set and blocks release until owners refresh it.

C. Regulated change illustrative

Pipeline routes the change to a human approver with evidence attached, so the decision lands within the day.

What broke, and what changed

Positive-only security scans looked clean. Adding negative DAST scenarios exposed an error response revealing server directory structure, plus log files leaking details to AI models. Negative testing then became a standard gate.
