PULSE is how I would make AI the default way a financial services firm builds software. Every change starts from something clients told us, moves through the full lifecycle with AI and agents doing the heavy lifting, and only counts as done when client satisfaction shows it worked. Then the loop starts again.

    How it works

    Creator agents build, judge agents check, people decide

    The same pattern runs at every stage, from discovery to release. Choose a sample artifact to see how a judge agent scores it against a rubric.

    Creator

    Creator agents

    • Group client feedback into themes
    • Draft stories and acceptance criteria
    • Write code, tests and release notes
    • Fix what the judge flags
    Judge

    Judge agents

    • Score every artifact against a rubric
    • Explain each score in plain words
    • Send work back with specific fixes
    • Collect the evidence for sign-off
    Person

    People

    • Choose which problems to solve
    • Approve requirements and releases
    • Own the rubrics and raise the bar
    • Can dispute a judge's score in one click

    First 90 days

    Listen, pilot one journey, then scale

    PULSE should earn its place with one client journey before it touches the rest. This is how I would sequence it.

    Days 1–30

    Listen and baseline

    • Meet engineering, product, risk, compliance and client-service leaders
    • Inventory the AI tools teams already use, and where releases slow down
    • Baseline lead time, change failure rate, CSAT and NPS for one journey
    Days 31–60

    Pilot one journey

    • Pick one client pain point with clear data and an eager team
    • Stand up creator and judge agents with rubrics owned by practice leads
    • Ship the first change through the full loop, with a named approver
    Days 61–90

    Scale and report

    • Publish the first scorecard, pairing delivery speed with client outcomes
    • Turn the pilot into a self-service path other teams can join
    • Present a 12-month roadmap with targets to leadership
    What I would commit to by day 90
    1. One client journey improved through the full loop, with CSAT measured
    2. Creator and judge agents running with agreed rubrics
    3. A baseline scorecard and a 12-month roadmap
